# Последний Король (FRPG)

Консольная текстовая RPG на Java. Герой поднимается по уровням, выбирает между веткой атаки и веткой защиты, сражается со случайными врагами и проходит через 4 акта истории до финального босса.

## Требования

- Java 17+

## Запуск

```bash
./gradlew run
```

На Windows в `cmd.exe` для корректного отображения кириллицы переключите кодовую страницу консоли перед запуском:

```bash
chcp 65001
```

(PowerShell и большинство современных терминалов в этом не нуждаются.)

## Сборка

```bash
./gradlew build
```

Собирает проект, прогоняет тесты и кладёт runnable jar в `build/libs/frpg-<version>.jar`.

## Запуск собранного jar

```bash
java -jar build/libs/frpg-1.0.0.jar
```

## Готовые сборки

Собранный jar для каждого релиза доступен во вкладке [Releases](../../releases).
